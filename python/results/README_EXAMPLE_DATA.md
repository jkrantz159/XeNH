# About the Example Data

## ⚠️ IMPORTANT: This is SYNTHETIC Data

The file `success_example.csv` contains **SYNTHETIC/MOCK DATA** for demonstration purposes only.

### What This Means

- ✅ **Realistic parameter distributions** based on literature (Parai & Mukhopadhyay 2018, Barry & Hilton 2016)
- ✅ **Shows expected output format** for successful parameter combinations
- ❌ **NOT validated** against actual Xe and N success criteria
- ❌ **NOT generated** from running the Monte Carlo simulation

### Why Synthetic Data?

1. **True successes are rare**: Finding parameters that simultaneously satisfy both Xenon AND Nitrogen constraints requires millions of trials
2. **Time intensive**: Real simulation takes 9+ hours for 1 million trials
3. **Demonstration purpose**: Shows what the output looks like without waiting

### How It Was Generated

```python
# From generate_example_data.py
# Parameters drawn from realistic distributions but NOT tested
alpha = 10 ** np.random.normal(-8.8, 0.3)  # ~1e-9
beta = np.random.normal(3e9, 0.5e9)         # 2-4 Ga
eta = np.random.uniform(7.6e-10, 7.9e-10)   # Narrow range
```

### Getting Real Validated Successes

To generate actual validated successes, run:

```bash
cd python/src

# Quick test (100k trials, ~55 min)
python run_quick_test.py

# Full simulation (1M trials, ~9 hours)
python run_simulation.py
```

Real successes will:
- ✅ Be tested against Xe concentration and isotope ratio criteria
- ✅ Be tested against N concentration and isotope ratio criteria
- ✅ Only save parameters where BOTH models succeed
- ✅ Be saved to `success_100k.csv` or `success.csv`

### Expected Success Rate

Based on the parameter space and constraints:
- **Very low**: < 0.01% of random trials
- **1M trials**: May find 10-1000 successes
- **Depends on**: Parameter range choices and success criteria
