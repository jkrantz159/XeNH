# Data Directory

This directory is for input data files if needed for your simulations.

## Expected Files

The main scripts will look for success files in the `results/` directory:
- `success.txt`: Combined Xe-N success parameters
- `IndXeNHsuccess.txt`: Independent Xe-N-H success parameters
- `LowLVIndXeNHsuccess.txt`: Low late veneer success parameters

## Example Data Format

Success files should be CSV format with the following columns:

### For `success.txt` (7 columns):
```
alpha,beta,eta,Xed,Nd,Resfrac,LVfrac
1.23E-09,3.45E+09,7.65E-10,1.23E+06,4.56E+15,0.9,1.0
```

### For `IndXeNHsuccess.txt` (11 columns):
```
eta,Hd,Ha,Hb,Nd,Na,Nb,Xd,Xa,Xb,Resfrac
7.65E-10,1E15,1E-09,3E09,1E15,1E-09,3E09,1E06,1E-09,3E09,0.9
```

## Note

This directory is intentionally left empty. Data files will be generated by running simulations or can be placed here for analysis.
